聚合AI工作台设计讨论

Video Making & 新媒体运营 · AI Workbench 技术方案 · 导出于 2026年9月5日

User 我需要帮朋友设计一个聚合AI工作台,mainly focus on Video making 和新媒体运营。技术上的功能点主要是：
1、语音转文字，帮主播做角色画像、赛道分析、直播中口播的卡点错误分析，需要录制全程直播然后转写
2、简单的文生图、文生视频需求，用户完全外行 to prompt engineering，需要先搭一个workflow
Claude

两个方向是完全不同的技术栈,但可以共享同一个"数据层"(主播/项目资料库)。

模块一：直播分析(语音转文字 → 画像/诊断)

  • 录制环节：优先用OBS本地录制文件，质量最稳定；抓平台直播需注意合规性
  • ASR选型：中文直播场景建议用阿里云/腾讯云/讯飞等做过电商直播优化的模型，效果优于Whisper
  • 长音频需分段+流式转写，并做说话人分离(diarization)区分主播与场控/嘉宾
  • 分析层：角色画像（语言风格/口头禅/卖点话术）、赛道分析（对比同赛道话术/选品）、口播卡点分析（结合ASR时间戳做时间轴标注，精确到分秒）

模块二：文生图/文生视频（隐藏prompt engineering）

  1. 意图收集：用选择卡片代替自由输入（风格/品类/场景）
  2. 表单 → prompt生成器：LLM把选项拼装/润色成真正的prompt
  3. 参考图驱动：支持image-to-image
  4. 结果迭代按钮："更简约""换背景"等一键操作，而非重写prompt
  5. 图生视频：图片定稿后再接图生视频模型，成功率比直接文生视频更高
User 尽量用免费模型
Claude

核心思路：开源模型本地部署 + 少数有免费额度的国产API补充

ASR（免费开源）

  • FunASR（阿里达摩院开源）— 中文直播场景首选，自带标点恢复+说话人分离
  • 备选 Whisper large-v3 做交叉验证
  • 部署：消费级GPU或魔搭社区(ModelScope)免费在线demo

分析层LLM（免费/低成本）

  • DeepSeek-V3/R1 — 价格极低，中文分析能力强，做主力
  • 通义千问 Qwen2.5 — 开源可本地部署
  • 智谱 GLM-4-Flash — 官方长期免费，适合量大但简单的任务

文生图/文生视频（开源免费）

  • FLUX.1 [schnell] — 开源免费，速度快
  • Stable Diffusion XL/SD3.5 — 生态成熟，适合精细控制
  • Wan2.1（通义万相开源版）— 中文场景优化好，支持图生视频
  • CogVideoX（智谱开源）— 轻量备选

提醒：开源文生视频质量目前仍不如可灵/即梦等商用闭源模型，MVP阶段验证workflow足够，正式交付可能需要"开源跑量+商用精修"混合方案。

  • 蝉妈妈已推出"蝉妈妈AI"，集成DeepSeek/豆包Seed，提供AI运营分析、图片设计、智能剪辑、文案生成；孵化"蝉镜"视频创作平台，基于5000万条爆款视频构建"黄金3秒开头""转化钩子文案"等算法模型

  • 结论：需求真实，但巨头已布局，差异化机会在于服务中小主播/新人主播的轻量、便宜、数据自控方案

Coze可以用，但建议分阶段用。

  • Coze适合快速搭建workflow demo验证逻辑，无代码、可视化，几天出demo
  • 但更适合"验证逻辑"而非"最终产品"——不适合自定义品牌/用户体系/计费
  • Coze内置ASR是豆包自研模型，不是FunASR，长音频处理能力需实测
  • 开源替代：Dify（可自部署，接自定义API）或字节开源的 Coze Studio

建议路径：Coze/Dify搭demo → 真人测试验证 → 有效后迁移核心逻辑到自建后端+前端

User 图生视频这一步Wan模型具体怎么调用
Claude

阿里云百炼(DashScope)图生视频是异步任务：提交任务拿 task_id，轮询状态，完成后取视频URL。

第一步：提交任务

curl -X POST 'https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis' \
  --header 'X-DashScope-Async: enable' \
  --header "Authorization: Bearer $DASHSCOPE_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "wanx2.1-i2v-turbo",
    "input": {
      "prompt": "镜头缓慢推进，产品在旋转展示",
      "img_url": "https://你的图片公网地址.jpg"
    },
    "parameters": {
      "resolution": "720P",
      "duration": 5
    }
  }'

第二步：轮询任务状态

curl -X GET "https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}" \
  --header "Authorization: Bearer $DASHSCOPE_API_KEY"

实操要点

  • 图片必须是公网可访问URL，不能传本地文件/base64
  • model选择：wanx2.1-i2v-turbo/plus做标准图生视频；wan2.2-s2v可实现图+音频直接生成对口型数字人视频
  • 后端设计成"提交后台任务+轮询/webhook"，前端给进度提示，轮询间隔3-5秒
  • Coze里可用"插件"节点配置HTTP请求封装这套逻辑
