【手机网页交互原型】

▶ 文件与预览
• 页面：prototypes/mobile.html，纯 HTML/CSS/JavaScript，无第三方依赖。
• 可用浏览器直接打开文件。
• 本机预览命令（在项目根目录执行）：

```bash
python3 -m http.server 8090 --bind 127.0.0.1 --directory prototypes
```

• 然后访问 http://127.0.0.1:8090/mobile.html。
• 该命令只提供原型目录，避免暴露项目根目录中的密钥与交接文档。
• 初次部署入口为 /mobile；现已迁至 https://ai.pannel.kris42y.tech/mobile-preview 。
• /mobile 与 / 现均使用正式工作台的响应式手机布局，不再展示本目录独立演示。详见 ../移动端微信布局修复记录.md。
• 发布使用临时白名单目录，只包含 index.html、vercel.json、prototypes/mobile.html 与项目关联配置，未上传交接文档或密钥。
• 首次部署编号：dpl_fqQvvJHzETQw2kyb9ni45fmVGEt7；最新部署编号：dpl_285mDaoTcVc242Gw1XFg1XiT6S72。

▶ 边界
• 不调用 AI，不产生额度消耗，不持久化输入，不读取真实会话。
• 示例海报不按描述或参数生成，也不承诺下载后直接进入手机相册。
• 此独立原型不连接后端。后续正式 index.html 已完成手机布局修复，后端未修改。
