【二、已确定的产品边界】

• 面向最多10名外部受邀测试用户，用户名＋密码，不绑定邮箱或手机号。
• 自然语言对话是主创作入口，支持咨询、文案、图片、AI视频及明确标识的本地运镜；不是仅限电商。
• Gemini 3.8 Flash经官方agy CLI处理对话和请求受控工具；固定具体型号，不用auto／flash别名或不披露的其他模型替代。
• 生图使用Agnes Image 2.5 Flash；AI视频使用Agnes Video 2.5 Flash。Google媒体备用未启用，不自动开通付费通道。
• 同一用户每次新建对话，也必须建立新的独立CLI会话和上下文。“新窗口”指独立创作上下文，不增加强制浏览器弹窗。
• 暂不设置每日、每用户、全站业务用量或存储配额；不实现额度扣减和余额面板。供应商自身限额、反滥用、并发排队及磁盘保护仍保留。
• 暂不实施备份，不承诺灾损恢复。保存现有数据库与依据任务ID续查仍是必须能力，不等于备份。
• 用户原图与作品保留到主动删除；磁盘不足暂停新增，不静默删除旧作品。
• 继续使用当前机器及 https://ai.pannel.kris42y.tech 。不新增云主机、域名或收费资源，不在本轮修改DNS、Vercel或隧道。
• 共享许可未独立核验仅作风险记录，不作为当前受控测试前置，不再反复询问；不宣称得到官方许可。长期对外、收费或扩大规模时重新评估。

【三、首版能力与用户流程】

▶ 核心闭环
新建对话 → 输入需求／上传参考图 → 理解并执行明确请求 → 对话展示真实状态及作品 → 选定作品版本修改、下载或进入基本精修。
咨询不自动生成；指代不明、必要信息缺失时补问，已明确的画幅、主体、时长和动作从当前对话继承。
默认生成一张视觉稿。明确多方案时逐项生成，不因无业务配额而无限批量生成。

▶ 视频路径
1. 有明确参考图：默认首帧keyframe驱动，绑定具体图片版本。
2. 没有图：先生成视觉确认稿，用户确认之后再创建视频任务。
3. 明确要求直接文生视频：走text路径，不冒称主体与文字能严格保真。
4. 明确选择本地快速运镜：调用本地FFmpeg，标注非AI动态生成。
5. 新版图片不会替换旧视频任务的参考图。修改动作通常是基于同一图片重新生成，而非编辑原视频；Flash不支持的参考视频输入明确拒绝。

▶ 首版接口覆盖
账号与管理员基础操作、持久对话／消息轮次、流式事件、图片上传、图片生成／参考图修改、AI视频、本地运镜、真实任务、作品版本与下载／删除。
基本精修复用同一任务接口，不建立另一条生成通道。图生图、不同参考素材的保真仍待实测，接口支持不等于质量验收完成。
旧直播分析、语音转写、复杂剪辑不纳入本次新增接口契约；保留旧源码与数据，不在本轮下架已有站点。新界面是否保留这些旧入口仍在发布前确认。

【五、技术栈与职责】

▶ 已确认技术栈
前端Vue 3＋Vite；后端Python＋FastAPI；SQLite保存事实状态；独立Python媒体worker；systemd托管服务。
首版不引入React重写、Redis、多机队列或Docker部署。具体包版本在独立环境验证并锁定，不修改全局运行时。

▶ 服务分层
浏览器 → FastAPI身份／对话／任务接口 → 常驻会话管理器 → 官方agy CLI → 受控MCP工具网关 → 统一任务服务 → 独立媒体worker → Agnes／FFmpeg。
API只负责校验、持久化与调度，不在请求生命周期中同步等待几十秒的视频完成；FastAPI BackgroundTasks不作为持久任务队列。
文字增量与工具动作是两种事实，开启流式不能绕过媒体执行分支。
systemd守护进程与重启策略不能替代用户隔离、授权控制或数据备份。

▶ CLI独立会话
• 应用conversation_id与CLI conversation_id分开，只有服务端持有映射；API不暴露CLI ID、PID或目录。
• 新对话首次发送时启动新CLI，不带--continue或旧--conversation，绑定新返回的CLI ID。
• 同一创作对话持续多轮采用--input-format stream-json --output-format stream-json；收到本轮result后再开始下一轮。
• 同一用户A／B对话及不同用户必须使用不同进程／CLI ID和受控上下文；不自动读取其他会话历史或共享工作目录。
• 打开旧对话只接回原进程，或按已校验归属的明确CLI ID恢复；禁止全局“最近一次对话”。
• 空闲可回收，不删除对话／作品；不把带旧上下文的进程转交另一对话。多个浏览器视图指向同一对话时，不重复启动或重复提交。
• CLI内部usage、num_turns和duration_seconds可能累计，不能按每轮重复累加。
• 会话管理器崩溃后根据数据库租约核对；无法确定某轮执行情况时标记待核对，不盲目重放整轮造成重复生成。

【六、数据与状态】

核心对象：users、invites、login_sessions、password_reset_tokens、conversations、messages、runs、tasks、artifacts、artifact_versions、reference_confirmations、events、idempotency_records、audit_events。
run代表一次用户消息触发的文字／工具协调轮次；task代表真实媒体执行。一个run可以产生多个task，run结束或停止不代表其task被取消。
消息序号、事件序号稳定；作品版本不可变；输入引用绑定版本。SQLite外键、短事务和唯一约束保障归属、幂等与映射，不在网络等待期间长时间持有写事务。
媒体文件独立存储，消息／数据库只保存受保护引用和元数据。公开响应不返回主机路径、供应商凭据或临时取图签名。

▶ 任务状态
queued → submitting → running → saving → completed。
异常／停止状态：failed、canceled、submission_unknown、needs_reconciliation。
提交前先记意图，成功受理后保存供应商任务ID；仅文件已落盘且基本校验通过才completed。供应商完成但下载失败仍在saving或待恢复，不伪装成功。
已受理任务重启后续查；下载失败重取同一结果；未确定是否受理时不自动再次POST。不声称外部API与本地数据库实现严格exactly-once。

▶ 对话轮次状态
queued、running、stopping、completed、failed、canceled、interrupted、needs_reconciliation。
同一对话可以接收排队消息，但只串行执行一个run；run构建上下文只使用截至该用户消息的可见历史，不提前带入后面排队的消息。
停止run只阻止该轮继续输出和新增工具动作；已经持久受理的媒体任务继续核对／收尾，不冒充全部撤销。

【七、接口与执行规则】

外部接口前缀/api/v1，使用应用账号Cookie鉴权、CSRF保护与稳定错误码；API响应与生成的OpenAPI为新设计，不是旧server.py路由清单。
创建消息返回202及run；创建媒体任务返回202及task；前端经SSE和查询接口观察状态，数据库为最终依据。
新建对话、消息、上传和任务创建要求Idempotency-Key；重复请求不能重复创建作品或调用提供方。必须先校验当前身份和归属，再返回历史幂等结果。
前端通过明确图片确认动作取得reference_confirmation_id，再用于首帧视频；模型不能自造confirmed=true作为确认依据。自然语言明确选图也必须由服务端绑定具体版本及原消息证据，不能仅接受模型声明。
精修可直接调用任务接口，Gemini通过内部工具调用同一任务服务；MCP不作为匿名公网执行接口，不接受模型指定用户、任意URL、文件路径、shell或供应商key。
供Gemini访问的作品范围仅为当前对话及用户显式引用的版本；用户自己的全局作品列表不等于允许模型在新对话自动遍历旧作品。

【八、安全、费用与文件生命周期】

管理员由项目所有者持有，通过本地一次性命令建立，不设默认密码。邀请注册；人工核验身份后签发一次性重置链接，重置成功撤销旧登录。
密码使用Argon2id；邀请／重置／登录凭据仅保存必要校验值，不记录密码或一次性链接。管理员界面不提供浏览私密聊天和作品的入口，但不宣称服务器所有者无法访问磁盘或具有端到端加密。
HTTPS、HttpOnly／Secure Cookie、CSRF、精确同源策略、登录防爆破、逐资源归属验证不可省略；HEAD和Range下载同样验证身份。
临时供应商取图授权限时、绑定具体文件和任务；不公开uploads整个目录，不让模型提交任意目的地URL。上传限制类型、字节和解码像素，下载检查目的地／重定向和容量。
只加载必要MCP并精确放行，拒绝宿主文件／终端／其他服务访问，不使用--dangerously-skip-permissions。--sandbox主要约束终端，不等于整个Agent已经安全封闭，须实际验证。

业务配额不实施，但免费状态未知／到期、供应商限额或低磁盘时暂停新增；不删除旧作品、不自动换收费模型。agy的AI Credit Overages／useG1Credits需核对，不因本地未见字段就宣称不会花费。
删除聊天默认不连带删除作品；删除作品立即撤销在线访问，物理清理窗口采用可配置设计值。正在执行的任务仍依赖某输入时拒绝物理删除，避免偷偷让任务失去输入。
当前不做备份，误删、盘损或数据库损坏可能不可恢复；仍保留正常进程重启后的任务续查。未来备份另行设计，不自动恢复v0.1方案。

开发与内测使用独立目录、进程、端口、数据库和素材；Git worktree不是运行隔离。后端／任务服务受systemd托管，线上切换须单独批准。

暂不做备份，代码版本可保留，但数据库破坏性迁移不能承诺无损回滚，须单独评估。
监控排队、任务耗时、提供方异常、进程退出、剩余磁盘和授权失效；不新增业务配额面板。

AC-07：免费未知／到期、提供方限额、磁盘不足时不提交新生成，不收费回退、不删作品；没有本地日配额。

AC-12：文档／OpenAPI结构检查通过后，仍须用实际FastAPI路由做请求、权限、CSRF、幂等与状态机测试；文档验证不是接口实现测试。
