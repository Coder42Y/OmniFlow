▶ 停止
在上述工作目录执行：
```bash
touch .superpowers/autodev/STOP
```
控制器每秒检查，终止自己创建的pi进程组并保存暂停状态。也可在tmux窗口按Ctrl+C。不要pkill pi、pkill agy或tmux kill-server，以免伤及其他会话。

▶ 明确恢复
先检查status.json和暂停原因，确认原进程结束并解决授权／测试／磁盘问题，再在工作目录执行：
```bash
rm .superpowers/autodev/STOP  # 仅在该标记存在且确认恢复时执行
tmux -L omniflow-dev respawn-pane -t coding -c "$PWD" '/usr/bin/python3 -u tools/autodev.py --resume'
```
没有STOP标记时跳过rm；respawn-pane不带-k，拒绝覆盖仍在运行的窗格。恢复跳过已通过阶段，从当前未完成阶段重新检查；不自动跳过失败，也不重放生产生成任务。
若服务器已经重启，临时tmux宿主也会消失，需先按tools/autodev.py与本说明重新建立宿主，再显式--resume，不声称重启自动恢复。
