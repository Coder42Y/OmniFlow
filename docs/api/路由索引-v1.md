  不返回进程路径、数据库位置、凭据或完整供应商诊断。未就绪503 Problem。

  请求：无请求体；成功：200 Capabilities。
  查询实际模型能力、可用性与安全上限

  消费邀请并注册登录

• POST /auth/login — 登录并轮换会话

• GET /auth/me — 读取当前用户

  读取当前用户

• POST /auth/logout — 撤销当前登录并清理Cookie

• POST /auth/password-resets/validate — 校验重置链接而不消费

  校验重置链接而不消费

▶ 对话

• POST /conversations — 创建全新的独立创作对话
  operationId：create_conversation；鉴权：登录＋CSRF；幂等键：必须。
  请求：application/json / ConversationCreate；成功：201 Conversation。
  不接受CLI ID。CLI可首次发消息才启动；绝不继承旧对话上下文。

• GET /conversations — 列出自己的对话
  operationId：list_conversations；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 ConversationPage。
  列出自己的对话

• GET /conversations/{conversation_id} — 读取自己的对话元数据
  operationId：get_conversation；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 Conversation。
  读取自己的对话元数据

• PATCH /conversations/{conversation_id} — 修改对话标题
  operationId：rename_conversation；鉴权：登录＋CSRF；幂等键：不要求。
  请求：application/json / ConversationPatch；成功：200 Conversation。
  修改对话标题

• DELETE /conversations/{conversation_id} — 删除对话但不连带删除作品
  operationId：delete_conversation；鉴权：登录＋CSRF；幂等键：不要求。
  请求：无请求体；成功：204 无响应体。
  有未结束run或非终态task时409 RESOURCE_IN_USE。删除网站记录不等于即时清除第三方留存。

• GET /conversations/{conversation_id}/snapshot — 取得同一数据库快照下的最近消息与状态
  operationId：get_conversation_snapshot；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 ConversationSnapshot。
  最近50条消息按seq升序，附更早消息游标；包含非终态run/task及所需作品版本，last_event_id与这些数据同一读事务产生。

• GET /conversations/{conversation_id}/messages — 分页读取对话消息
  operationId：list_messages；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 MessagePage。
  每页按seq升序显示；cursor指向更早一页。无cursor时返回最近limit条。

• POST /conversations/{conversation_id}/messages — 保存消息并排队一个主控轮次
  operationId：create_message；鉴权：登录＋CSRF；幂等键：必须。
  请求：application/json / MessageCreate；成功：202 MessageAccepted。
  内容与附件不能同时为空；同一对话run串行，后发消息可排队。客户端不能上传assistant/system历史、用户ID、CLI ID或任意模型。

• GET /conversations/{conversation_id}/runs — 查询对话轮次含待核对状态
  operationId：list_runs；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 RunPage。
  查询对话轮次含待核对状态

• GET /runs/{run_id} — 查询自己的单个主控轮次
  operationId：get_run；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 Run。
  查询自己的单个主控轮次

• POST /runs/{run_id}/cancel — 请求停止一个文字轮次而非取消媒体
  operationId：cancel_run；鉴权：登录＋CSRF；幂等键：不要求。
  请求：无请求体；成功：202 Run。
  queued可直接canceled；running先stopping。已经受理的媒体task继续，完成后的run返回409。重复停止请求返回当前状态。

▶ 事件

• GET /conversations/{conversation_id}/events — 订阅本对话持久事件流
  operationId：stream_events；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 二进制或流。
  只读订阅，不启动run或任务。Last-Event-ID优先于query游标；必须使用应用事件，不透传CLI日志。过期游标在开始流前返回410。

▶ 任务

• POST /tasks — 通过统一服务创建一个媒体任务
  operationId：create_task；鉴权：登录＋CSRF；幂等键：必须。
  请求：application/json / TaskCreate；成功：202 Task。
  每task一份媒体。精修入口显式提交，Gemini经内部受控网关调用同一任务服务；参数和确认事实必须由后端校验。

• GET /tasks — 查询自己的媒体任务
  operationId：list_tasks；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 TaskPage。
  查询自己的媒体任务

• GET /tasks/{task_id} — 查询真实媒体状态
  operationId：get_task；鉴权：登录；幂等键：不要求。
  请求：无请求体；成功：200 Task。
  查询真实媒体状态

• POST /tasks/{task_id}/cancel — 仅取消尚未提交的媒体任务
  operationId：cancel_task；鉴权：登录＋CSRF；幂等键：不要求。
  请求：无请求体；成功：200 Task。
  只允许queued→canceled，与worker领取原子互斥；其他非可取消状态409 TASK_NOT_CANCELABLE，绝不伪称供应商已撤销。

• POST /tasks/{task_id}/recover — 仅续查或重新下载同一供应商结果
  operationId：recover_task；鉴权：登录＋CSRF；幂等键：不要求。
  请求：无请求体；成功：202 Task。
  不新建task、不再次生成。有可核对供应商任务ID/结果线索才可恢复；提交未知且无线索409 RECONCILIATION_REQUIRED。

▶ 作品

• POST /conversations/{conversation_id}/reference-confirmations — 明确确认图片版本用于本对话首帧视频
  operationId：confirm_reference；鉴权：登录＋CSRF；幂等键：必须。
  请求：application/json / ReferenceConfirmationCreate；成功：201 ReferenceConfirmation。
  必须是自有可用图片版本。此动作是用户确认事实，不向MCP开放，模型不能自造确认。

• POST /uploads — 上传图片并建立不可变版本
  operationId：upload_image；鉴权：登录＋CSRF；幂等键：必须。
  请求：multipart/form-data / UploadInput；成功：201 ArtifactCreated。
  multipart/form-data；只接收可解码JPEG/PNG/WebP，限额见capabilities。幂等摘要使用文件字节及语义字段，不含multipart边界。

• GET /artifacts — 列出自己的作品，不向模型默认注入其他会话作品
  operationId：list_artifacts；鉴权：登录；幂等键：不要求。

  列出自己的作品，不向模型默认注入其他会话作品

  请求：application/json / TextArtifactCreate；成功：201 ArtifactCreated。

• GET /artifacts/{artifact_id} — 读取作品及当前版本标识

• DELETE /artifacts/{artifact_id} — 撤销作品及所有版本访问并排队物理清理

  请求：无请求体；成功：202 DeletionReceipt。
  任务占用时409 RESOURCE_IN_USE；已生成的派生视频不连带删除。不承诺撤回已下载或已送达提供方的副本。

• GET /artifacts/{artifact_id}/versions — 分页读取作品历史版本

• GET /artifacts/{artifact_id}/versions/{version_id}/content — 受保护文件读取、播放及下载
  operationId：get_artifact_content；鉴权：登录；幂等键：不要求。

  受保护文件读取、播放及下载

• HEAD /artifacts/{artifact_id}/versions/{version_id}/content — 鉴权后读取文件头，不返回响应体

▶ 供应商取图

• GET /media-grants/{grant_id}/content — 供应商按短期授权读取唯一参考图片
  operationId：get_provider_reference；鉴权：供应商短期取图凭据；幂等键：不要求。
  请求：无请求体；成功：200 二进制或流。
  不需要网站Cookie；只允许后端签发、绑定具体版本和任务的token。失效/撤销/错误凭据统一404，不接受任意路径，不公开整个素材目录。

• HEAD /media-grants/{grant_id}/content — 供应商验证参考图片文件头
  operationId：head_provider_reference；鉴权：供应商短期取图凭据；幂等键：不要求。
  请求：无请求体；成功：200 无响应体。
  与GET使用同一短期授权，不返回响应体；token及完整URL必须从访问日志中脱敏。

▶ 管理

• GET /admin/invitations — 列出邀请元数据，不返回历史凭据
  operationId：admin_list_invites；鉴权：管理员；幂等键：不要求。
  请求：无请求体；成功：200 InvitePage。
  列出邀请元数据，不返回历史凭据 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• POST /admin/invitations — 签发一次性邀请，完整链接仅返回本次
  operationId：admin_create_invite；鉴权：管理员＋CSRF；幂等键：不要求。
  请求：application/json / InviteCreate；成功：201 InviteIssued。
  不记录完整链接。失败不能自动重试发新邀请；通过列表核对或撤销后重新签发。 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• POST /admin/invitations/{invitation_id}/revoke — 撤销未消费邀请
  operationId：admin_revoke_invite；鉴权：管理员＋CSRF；幂等键：不要求。
  请求：无请求体；成功：200 Invite。
  撤销未消费邀请 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• GET /admin/users — 查询账号元数据
  operationId：admin_list_users；鉴权：管理员；幂等键：不要求。
  请求：无请求体；成功：200 UserPage。
  查询账号元数据 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• PATCH /admin/users/{user_id} — 停用或启用账号
  operationId：admin_set_user_status；鉴权：管理员＋CSRF；幂等键：不要求。
  请求：application/json / UserStatusPatch；成功：200 User。
  不能停用唯一管理员。停用撤销登录与媒体grant、拒绝新增及未提交执行；已受理任务仅继续核对终态，不删除作品。 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• POST /admin/users/{user_id}/password-resets — 人工核验身份后签发重置链接
  operationId：admin_issue_password_reset；鉴权：管理员＋CSRF；幂等键：不要求。
  请求：application/json / PasswordResetIssue；成功：201 PasswordResetIssued。
  服务端验证管理员，不以请求中的核验方式代替真实人工核验。不能查看旧密码；URL仅本次返回，重发使该用户旧重置凭据失效。 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• GET /admin/tasks — 查看不含私密内容的任务故障概况

  请求：无请求体；成功：200 OperationalTaskPage。
  查看不含私密内容的任务故障概况 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• GET /admin/generation-policy — 读取本地暂停开关
  operationId：admin_get_generation_policy；鉴权：管理员；幂等键：不要求。
  请求：无请求体；成功：200 GenerationPolicy。
  读取本地暂停开关 必须校验admin角色；Cookie鉴权本身不代表管理员授权。

• PATCH /admin/generation-policy — 暂停或恢复接收新请求
  operationId：admin_patch_generation_policy；鉴权：管理员＋CSRF；幂等键：不要求。
  请求：application/json / GenerationPolicyPatch；成功：200 GenerationPolicy。
  关闭后拒绝新入队并暂停尚未提交的同类工作；已由供应商受理的继续收尾。恢复本地开关不覆盖供应商限额或费用保护，不允许设置key、模型、额度或收费回退。 必须校验admin角色；Cookie鉴权本身不代表管理员授权。
