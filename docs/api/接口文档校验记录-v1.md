▶ 检查结果
• 40个路径、51个HTTP操作、64个schema。
• 官方OpenAPI3.1元schema结构验证通过。
• 525个内部引用全部可解析；operationId唯一，路径参数完整且必填。
• 22个契约示例、8个接口正文JSON示例及1个SSE帧通过schema验证。
• 22类无效输入被拒绝，包括任意model／URL／用户ID／文件路径、Flash视频错误时长／档位、缺失首帧确认、伪造角色／CLI ID、错误版本组合及超长消息。
• 所有状态修改操作声明CSRF；管理员操作声明角色要求；用户下载／HEAD声明会话鉴权；供应商取图使用单独的短期媒体凭据。
• 检查HEAD及204无响应体、Range具备200／206／416、事件流具备过期游标410、关键创建操作声明幂等冲突和删除墓碑行为。
• 消息包含artifact_version_ids，作品版本包含execution_engine，以支持刷新后恢复作品卡片和区分AI视频／本地运镜。
• 生成器重建产物与仓库契约一致，路由索引覆盖全部操作。
• git diff --check通过；已批准横线波浪原型未修改。发现原有*.png忽略规则会遗漏其两张公开参考截图，因此仅为docs/specs/assets/files下这两个确切文件新增.gitignore例外；其他生成素材与预览凭据继续忽略。
